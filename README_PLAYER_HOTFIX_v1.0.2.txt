ENGLISH QUEST — FAMILY PLAYER HOTFIX v1.0.2

この版の目的
============
v1.0 / v1.0.1 の「画面遷移の瞬間に保存する」方式をやめ、
学習データが localStorage に書かれるたびに、
そのPLAYER専用データへ即時ミラーする方式へ変更しました。

これでPLAYER切替時の pagehide / reload タイミングに
進捗保存を依存しません。

導入
====
1. player-layer.js だけ今回のファイルへ置き換える
2. index.html の先頭scriptを次へ変更

<script src="./player-layer.js?v=1.0.2mirror" defer></script>

3. 画面右上が
   v1.6.2 · FAMILY
   になれば新しい版です。

既に壊れたデータについて
========================
v1.0 / v1.0.1 で既に上書き・初期化された値は、
コードだけでは元の値を推測できません。

中学生の元データは、PC側のバックアップJSONから1回だけ戻してください。

おすすめ復旧手順
================
1. v1.0.2を入れる
2. 中学生を選ぶ
3. PC側で保存した元のJSONを「記録」から読み込む
4. マップで PROGRAM 4 を選び直す
5. 大人へ切替
6. 大人で1語だけ進める
7. 中学生へ戻る
8. 中学生のEXP・P4進捗が保持されていることを確認
9. 大人へ戻り、大人の1語も保持されていることを確認

v1.0.2ではJSON読み込み時の persist() も即時に
現在PLAYER専用データへミラーされます。
