ENGLISH QUEST — RECORD FIX v1.7.3

修正点
========
PLAYER切替後、TOEIC/英検5級/P3の進捗が0語表示になる問題に対応。

原因：
- 起動直後、ホームが初期値（0語）で描画される
- その後record-fix.jsが追加教材の学習記録を復元する
- しかしホームの画面を再描画せず、初期値が残る

v1.7.3では復元後にホーム・表示中の図鑑・記録を再描画します。
保存形式・プレイヤーデータの移行処理は変更していません。

導入手順
========
1. record-fix.js だけ今回のファイルで上書き
2. index.htmlの該当行だけ変更

<script src="./record-fix.js?v=1.7.3" defer></script>

※ 引き続きplayer-layer.jsの後、app.jsの前に置きます。
※ その他のファイルは変更しないでください。

確認
========
1. 更新して右上が v1.7.3 · FAMILY DATA になることを確認
2. 大人のTOEICで1語完了
3. 中学生に切り替え、再び大人へ
4. 1語の表示が維持されるか確認
5. 大人でさらに2語完了したら合計3語になるか確認

今回のVM再現テストでは、v1.7.2で「保存は1語/表示0語」を再現し、
v1.7.3で「保存1語/表示1語」を確認済みです。
本番のブラウザ・GitHub Pagesでの動作は導入後の確認が必要です。
