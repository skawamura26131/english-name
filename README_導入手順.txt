ENGLISH QUEST v1.8.1 — 書き取り特訓（第1弾）
===============================================

■ 何が増える？

1. ホーム「苦手単語の書き取り特訓」
   選択中の教材から最大5語を選んで練習できます。
   過去のミス・書き取りミスがある単語を上に表示します。

2. 通常学習が終わった結果画面「今回の単語で特訓」
   その回で学習した単語をそのまま練習できます。

3. 書き取りの流れ
   ・お手本を見ながら、同じ単語を3回入力
   ・間違いはその場で表示。正しく書けるまで同じ回
   ・3回終わったら「この単語は終了」か「見ずに書く」を選択
   ・見ずに書く場合は英語を隠し、日本語だけ表示
   ・採点後に正しい綴りを表示。間違えたら再挑戦可能

4. スマホの自動修正対策
   アプリ内のテキスト入力欄に autocorrect=off を設定。
   autocapitalize=off、autocomplete=off、spellcheck=false も指定。
   ※ スマートフォンのOSやキーボードの設定によっては、
      予測候補や自動修正を完全に無効化できない場合があります。


■ インストール

1. 作業前に「記録 → バックアップJSON」を保存してください。

2. ZIPにある writing-drill.js を、GitHubリポジトリの
   index.html と同じ階層にアップロードしてください。

3. index.html のスクリプトが並ぶ箇所の最後に追加します：

   <script src="./toeic-steps.js?v=1.8.0" defer></script>
   <script src="./writing-drill.js?v=1.8.1" defer></script>

   既存の読み込み行はそのままにしてください。
   重要：writing-drill.js は他のJSの一番後ろに読み込みます。

4. ページを開き直すと、ヘッダーに
   v1.8.1 · FAMILY DATA
   と表示されます。


■ 安全設計／初回確認

・PLAYERの保存構造や record-fix.js は変更しません。
・新しい保存キーは作りません。
・特訓は単語を「思い出す」補助練習です。
・特訓終了ではEXP・王冠・復習日・学習履歴を変更しません。
・通常学習の「見ずに書く」判定のままの既存モードは維持します。

まずホームから任意の1語を特訓し、3回→見ずに書く→採点が
できるか確認してください。その後、通常学習後の結果画面から
「今回の単語で特訓」も試してください。
